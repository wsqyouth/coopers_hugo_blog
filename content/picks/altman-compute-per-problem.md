如果多花一美元，AI 能把同一道难题做得更好吗？按 Sam Altman 的回顾，几年前过了大约一美元，继续投入就很难换来更好的结果。现在他在谈一项估计耗费千万美元的数学工作。John Collison 紧跟着问：换成一亿、十亿，什么时候该停？这期最值得听的是，两个人对预算的追问始终没有被「智能会变便宜」这句话盖过去。

## 本期精华

- **有用的算力上限，与完成同一件事的成本，可以朝相反方向变动。** 让 GPT-4 接着写十万 token，不保证它能写好软件。模型能长时间推理、把任务分给多个 Agent 后，才多了将计算变成结果的方法。同类任务可能降价，而过去做不了的任务开始值得花钱。
- **探索时先看边界，交付时再看能不能做便宜。** Altman 估计，访谈所说的一项 Navier–Stokes 工作耗费约千万美元。他对一年后可能只需百分之一成本的判断是预测，也特意说后续工作的平均花费已经更低。节目没有给出通用的科研定价。
- **研发成本、机房成本、算力收入是三笔账。** 当客户愿意为稀缺的算力付更高价，每吉瓦收入可以上升。对话里的七百亿与二百亿美元，是一吉瓦基础设施的五年总拥有成本情景，用来讨论降成本的空间。
- **AI 帮人找漏洞，也会逼人重想防御。** 两人从 PHP 漏洞聊到系统架构；Altman 赞成继续改进沙箱，也质疑能力继续跨越时能否只依赖现有隔离。访谈里的极端硬件攻击是思想实验。
- **个人 Agent 的关口在于能把事办完。** 退货、填表是两个容易理解的起点。入口交给 Agent 后，用户依然需要可信的商家、配送与售后。客户对 token 计价的坚持也有类似理由：至少要能理解、比较和预判开支。
