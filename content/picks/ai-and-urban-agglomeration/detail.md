<h2 id="摘要">摘要</h2>
<p>住在市中心，像买了一张演唱会的前排票：房子更贵，换来的是离工作、朋友、展览和演出更近。陆铭讲起一位学生，听完这个比喻后，每个周末开始带孩子逛街、去博物馆，即使自己原来并不喜欢。这让“大城市值不值得留下”变成了一个具体问题：已经付出的住房成本、时间和精力，究竟换回了哪些真正用得上的机会？</p>
<p>在李翔与陆铭的这场对谈里，AI
加速集聚有两条不同的路径：制造业中标准化的岗位被替代，部分劳动者转向需要人口与客流的服务业；创新团队则需要高频、跨界、偶然发生的交流，因而可能更愿意进入中心城区。但人口流动的总体方向不等于每个人的选择，职业、生活偏好、社会关系与人生阶段都可能改变答案。后半场进一步追问：地方争产值为何未必增加全国福利，工时和公共空间怎样影响消费，AI
又如何改变大学教育、研究组织以及养老与基础设施的安排。</p>

<a id="第一部分--城市机会与个人选择"></a><h2 id="城市机会与个人选择">城市机会与个人选择</h2>
<a id="为什么有人逃离大城市又有人想回来01311304"></a>
<h3 id="city-opportunity">为什么有人逃离大城市，又有人想回来 <span class="picks-episode-time">（01:31–13:04）</span></h3>
<p>离开大城市和重新回来，可以发生在同一轮经济波动里。李翔问是不是已经很少有人再谈“逃离北上广”，陆铭的回答是仍然有人谈：就业机会受到冲击，生活压力还在，外来人口平等使用公共服务也有障碍。可是回到小城市，有些人又发现工作更少、生活服务不够丰富，尤其难以找到行业伙伴和兴趣相投、能够谈心的朋友。有人留下，有人离开，又有新人进入；他所说的长期集聚，包含这样的更替。</p>
<p>房价需要分成结果与原因来看。收入、就业和人口增长带来住房需求，高房价可以是繁荣的结果；但如果需求增长时建设用地和住房供应受限，价格又会成为挤出人口的原因。陆铭批评的是后一种机制：限制供地并没有阻止人来，却增加了留下的成本。</p>
<p>房价下跌也有两面。土地出让收入下降会给地方财政带来压力，住宅、店铺和办公室变便宜，却可能让家庭和企业重新进入。他用房价下降二三成后有人买得起房作例子，同时强调，这仍以家庭有一定收入实力为前提。较低价格提供了机会，不等于所有家庭都获得了购买能力。</p>
<p>北京、上海的消费数据是否也说明城市失去吸引力？陆铭承认，房地产会影响家电、装修等消费，但他不把它视为社零表现的主要解释，而是提出四个因素。前期以旧换新补贴会把以后才买的车或手机提前买掉，造成基数变化和“跨期替代”；线上购物的销售额不一定记在买家居住的城市；以商品为主的社零指标没有完整涵盖服务消费；年轻人口增长受限，也会削弱消费动力。这四种原因分别涉及购买时点、统计地点、统计范围和真实的人口变化，不能只用一个零售数字替它们作答。</p>
<a id="一座城市能装下多少人也会不会收缩13042700"></a>
<a id="集聚的总量生活的成本和城市的承载力必须分开判断"></a>
<h3 id="metro-capacity">一座城市能装下多少人，也会不会收缩 <span class="picks-episode-time">（13:04–27:00）</span></h3>
<p>城市容量首先取决于用什么边界计算。陆铭提醒，中国地级市、直辖市的行政范围很大，直接拿它们的人口与国外狭义城市比较，会产生误解。他在访谈中估算，东京都市圈约有
<strong>1.2 万平方公里、3700
万人</strong>；上海加苏州的面积可以与之相比，但若以上海市中心划都市圈，实际应考虑昆山、太仓等紧邻地区，而非把苏州中心城区也一并算进来，按他所述的这一范围，人口约
<strong>3100 万</strong>。这些是他用来解释比较口径的估算。</p>
<p>住房、学校、医院、养老和交通设施可以增加，供水条件也可以改变。上海的例子是“水质型缺水”：并非没有足够的水，而是可用水的品质受到限制。据陆铭介绍，青草沙水库增加了约
<strong>800 万至 1000
万人的自来水供应能力</strong>。所以承载力是可随建设变化的变量，不能把眼下的设施不足直接认作人口永远不能增加。</p>
<p>他还用韩国首尔周边约集中了全国一半人口、日本东京都市圈约三分之一人口作比较，并将日本约
1.2
亿人口、与长三角相近的国土面积放在一起帮助听众理解；他也提到英国伦敦周边约三分之一的口述估计。这些比较服务于同一个解释：服务业比重越高，人们越需要线下见面、学习、看演出和运动，集中能降低交往与使用服务的成本。中小城市也有服务业，差别在于规模能支持多少数量、品质和多样性。</p>
<p><strong>大城市也可能衰退。</strong>
李翔追问历史上有没有集聚逆转，陆铭先回答“非常少”，随后列出例外。技术和贸易方式变化，会重排城市优势：他用纽约港口连接哈德逊河内陆航运、上海位于长江入海口解释城市地位的变化。战争、灾害，计划经济时期工业布局的调整，以及资源枯竭，也可能造成收缩。他对中国东南沿海优势的判断有明确条件：经济对外开放，而且海运仍是国际贸易的主要方式。</p>
<p>对于持续流出人口的地方，他提出把生活和公共服务更多集中到县城或中心城区，发展适合当地条件的农业、旅游和资源产业。例如西北戈壁的光伏、盐湖养海鱼，都利用了当地条件；生态宜居、较低房价和慢节奏也可能吸引另一类居民，但改善生活品质有时需要国家支持。寻找新产业并不意味着每个地方都能逆转人口趋势。</p>
<p>景德镇是一个有具体积累的例子：瓷都的历史产业基础，从规模化生产延伸出大量小作坊，又有相关人才培养，吸引国内外年轻创作者。陆铭随即强调，类似机会并不普遍，不能凭这个成功故事推断每个人口流出城市都能照做。大学也可以通过四年的情感联系、实习机会留住年轻人，但前提是当地产业与专业相配套；反过来，企业也会因为大学和人才聚集而来。</p>
<a id="ai-集中在少数城市是否意味着差距越来越大26142921"></a>
<h3 id="city-gaps">AI 集中在少数城市，是否意味着差距越来越大 <span class="picks-episode-time">（26:14–29:21）</span></h3>
<p>“城市间的不平等是在扩大吗？”面对李翔的判断，陆铭先说不能这样概括。李翔接着提出
AI
高度集中在几个城市的例子，他承认，这在短期以及总量意义上成立：创新的集中度高于经济活动，经济活动的集中度又高于人口。但把时间拉长，人会向收入更高、机会更多的地方流动，因而可能缩小人均差距。</p>
<p>这不是把地方之间的经济总量说成会拉平。陆铭区分了三种与个人更有关的尺度：人均
GDP、扣除生活成本后的实际收入，以及无法完全用价格衡量的生活质量。大城市的工资更高，一碗面和住房也可能更贵；通勤、工作压力、休息时间，甚至中午能否回家吃饭睡一会儿，都会改变生活的感受。</p>
<p>根据自己的研究和国际经验，他判断中国一些人均差距在缩小，同时承认剩余差距仍然很大。这个判断应保留为他的研究结论。它也说明，AI
产业集中、地区总量拉开与个人福利改善，可以同时发生；阻止人迁入机会较多的地方，反而可能让潜在就业与收入增长无法实现。</p>
<a id="年轻人是不是都应该去大城市29213152"></a>
<h3 id="city-choice-criteria">年轻人是不是都应该去大城市 <span class="picks-episode-time">（29:21–31:52）</span></h3>
<p>并没有适用于所有人的建议。李翔转述一位硅谷创业人士劝年轻人去大城市、提升收入的说法，陆铭随即把答案限定到具体的人：先看职业，再看性格与生活偏好，还要看社会关系。</p>
<p>AI
等职业可能更需要大城市的团队、同行和机会；一些做文创、艺术的人，却会主动寻找小城市安静的环境。即使职业相同，能否接受较小的住房、较高的租金和较长通勤，对城市丰富生活有没有兴趣，也会改变选择。一个人在大城市没有亲友，又不喜欢建立新关系，能得到的吸引力就不同。人口流向描述的是许多人选择后的结果，不能替任何一个人排除自己的偏好。</p>
<a id="ai-为什么可能把人推向大城市又把部分活动拉向市中心"></a>
<a id="ai-团队在旧金山市中心找什么31523326"></a>
<h3 id="ai-city-center">AI 团队在旧金山市中心找什么 <span class="picks-episode-time">（31:52–33:26）</span></h3>
<p>他们寻找的是更容易发生的交流。陆铭观察到，互联网时代聚在硅谷的一些活动，在这一波
AI
创业中转向了旧金山市中心。他用三个特点解释这类创新：<strong>高频、跨界、随机</strong>。从事
AI
的人可能每天都需要交流，对象可能是哲学、伦理或设计领域的人，而一次关键接触，可能来自共同参加的活动，并非事先约好的会议。</p>
<p>线上沟通可以降低已知关系之间的联络成本，但这个例子强调的是，尚不知道该找谁、甚至还不知道会遇到什么问题时，人如何相遇。中心城区把不同活动和人放得更近，增加了这样的机会。这是陆铭对创新区位的解释，并不是说所有团队都必须租在中心区。</p>
<p>团队迁入也会带动技术岗位之外的工作。年轻人喝咖啡、下班喝酒、看戏，会让生活服务业跟着靠近。对另一些人而言，眼前的选择可能是去大城市中心做服务员，还是回老家开饮食店。AI
的地理影响因此会通过消费继续传导。</p>
<a id="留在哪座城市先辨认自己的机会再辨认自己真正使用的生活"></a>
<a id="这张城市前排票你用上了吗33263847"></a>
<h3 id="choose-a-city">这张城市前排票，你用上了吗 <span class="picks-episode-time">（33:26–38:47）</span></h3>
<p>同样学技术，大学生或博士生可以选择在中心城区住小而贵的房子，进入 AI
公司工作，也可能去小城市的公务系统做政府数字化。陆铭说，这没有标准答案。钱和职业机会是一部分，大城市是否好玩、这些生活是否适合自己，也是另一部分。</p>
<p>“前排票”比喻随后把抽象的城市价值变成了三笔已经付出的成本。第一笔是买房、租房时支付的城市便利溢价；第二笔是纳税人对博物馆、图书馆等免费设施的支持；第三笔是为了留在大家都愿意去的地方，承受竞争，牺牲一部分收入或生活质量。他对那些工作生活偏宅的学生说，住在大城市却不使用这些资源，<strong>“相当于你买了个演唱会的前排座位票，然后你打瞌睡”</strong>。</p>
<p>学生后来告诉他，自己每周末带孩子逛街、看博物馆，哪怕自己原来并不喜欢。这个故事里的改变是生活方式：已经承担了居住成本，就开始让自己和孩子接触城市能提供的东西。它不是要求每个人为了看展留城，更没有证明付出越多就必须留下。</p>
<p>陆铭自己也有安静生活、院子里种花的想象，并不喜欢喧闹或频繁社交。但大学教职，以及他喜欢的画展、音乐会，让大城市仍然适合他。他特别提醒，个人选择与向公众提出的普遍建议应当分开；不同人生阶段也能换地方，不必一辈子只住一座城。</p>
<p>把这段讨论用于个人选择，可以回看上个月真正见过谁、去过哪里、用过哪些服务，再把这些收益同住房、通勤和压力放在一起比较。这是依据访谈整理的阅读应用。更长远的检验，则是<a href="detail.md#care-and-return">身体变弱以后，这座城能提供什么照护</a>。</p>
<a id="第二部分--就业地方竞争与消费"></a><h2 id="就业地方竞争与消费">就业、地方竞争与消费</h2>
<a id="大国的市场优势怎样才能变成居民的便利38474714"></a>
<h3 id="big-country">大国的市场优势，怎样才能变成居民的便利 <span class="picks-episode-time">（38:47–47:14）</span></h3>
<p>人已经到了沿海工作，学校和住房资源却未必跟着到位。陆铭用财政转移支付仍按户籍原籍配置的情形，解释“大国治理”的一个具体问题：流入地教育、廉租房供给不足，流出地却可能出现学校没有学生、资源闲置。市场大带来的收益，要通过资源重新配置才能转成居民实际获得的服务。</p>
<p>他认为，国家规模的重要性在技术应用与国际博弈中同时上升。中文使用者和国内用户多，有助于模型及平台应用推向大市场；地缘政治竞争加强，又使大国的谈判与协调能力更加重要。这里的语言、市场规模是他提出的解释因素，并非“大国自然就会做好
AI”的充分条件。</p>
<p>中国的央地关系、地方间关系和人口流动制度，也不能直接套用美国联邦制的框架。在陆铭的叙述中，美国地方政府的债务处置和责任结构，与中国单一制国家不同；中国的土地、户籍和公共服务安排又带来自己的问题。过去全球化迅速推进时，研究更容易着眼自由贸易和投资，而低估国家规模及治理差异。</p>
<p>他用中国人均 GDP 从 2001 年约 1000 多美元，到访谈时约 1.4
万美元的口述比较，说明中国在全球研究议题中的分量变化。讨论的目的既是看到规模优势，也是承认规模使跨地区资源配置更复杂，研究与制度需要跟上。</p>
<a id="厂房留在原地岗位可能去了别处47145110"></a>
<h3 id="automation-and-jobs">厂房留在原地，岗位可能去了别处 <span class="picks-episode-time">（47:14–51:10）</span></h3>
<p>自动化替代的是一部分岗位，厂房和产值可以继续存在。陆铭先把经济分析简化到制造业与服务业：按他在访谈中的口述，第二、第三产业已占中国
GDP 的九成以上，超过
93%。制造业里大量标准化、流程化、可编码的任务，容易由机器人和软件承担，24
小时运行的黑灯工厂就是直观例子。</p>
<p>问题接着变成：原来在工厂就业的人，去哪里工作？他以骑手、专车司机上一份工作可能在工厂的经历作说明。部分人转向餐饮、配送、出行等服务，而这些工作往往需要人际接触，要靠人口规模、密度和流量支撑。于是，<strong>制造业减少用工，会把劳动者推向服务业；当接替工作的服务更依赖客流，就可能进一步把就业推向大城市。</strong>
小城市即使保住了工厂，也未必保住原有就业人数。</p>
<p>这条机制与<a href="detail.md#ai-city-center">AI
团队的跨界交流</a>不同：一个讨论工作结构和服务需求，一个讨论创新合作。它们解释了为什么技术让线上协作更便利，却仍可能增强集聚。</p>
<p>判断还有政策含义。如果误以为 AI
会让大家自然分散，就容易认为外来常住人口的公共服务不用急着改善；如果集聚会加强，陆铭认为改革的决心反而需要更大。他也直言，这会影响个人买房判断。但访谈没有给出转岗成功率、净就业测算或某座城市的房价预测，不能从一个就业机制直接推出具体购房结论。</p>
<a id="地方的增长为什么不自动汇成全国的福利"></a>
<a id="每个地方都争到产值全国会更好吗5111010855"></a>
<h3 id="local-competition">每个地方都争到产值，全国会更好吗 <span class="picks-episode-time">（51:11–01:08:55）</span></h3>
<p>每个地方都建一家汽车厂，当地投资增加了，全国却可能出现重复建设和产能过剩。陆铭用这个例子区分三组目标：短期与长期、本地与全国、单一产值与多方面福利。借债投资可以抬高眼下的增长，若后来还不起债，不能就此视作长期成功。</p>
<p>地方竞争也不是中国独有。李翔提到亚马逊寻找第二总部时各地竞逐的例子，并追问中国是否有类似现象。陆铭的解释是，中国地方政府能够影响土地用途、建筑高度等条件，招商还与税收结算紧密相连。全国总部通常只有一个，但地区总部、独立法人和结算中心仍可争取：让企业在本地独立结算，税收和产值就更可能留在本地。</p>
<p><strong>地方竞争既曾推动增长，也一直带有代价。</strong>
李翔问，强调县域竞争创造经济奇迹，与批评地方分割市场是否矛盾。陆铭承认，发展早期缺资本，各地争投资有利于积累；鞋子、珍珠等产业可以在许多地方发展，彼此未必冲突。当收入低、基本需求尚未满足时，有工作和增长也更容易成为首要目标。</p>
<p>到了汽车、大飞机、AI
等需要较大规模与配套的行业，如果各地仍追求同一产业齐全，就更容易重复建设。居民同时开始要求更好的医疗、教育、养老、环境和文化服务，只盯产值的评价也会漏掉这些收益和代价。李翔把回答归纳为“阶段性有利、后来不利”，陆铭又补了一层：<strong>早期也有市场分割，只是它的坏处常被忽视。</strong>
他甚至认为，今天市场整合比上世纪八十年代好，当年还存在相邻县不让对方产品进入等现象。因此，他批评的是竞争方式与当下目标不匹配，并非说市场分割一直在单向恶化。</p>
<p>招商本身也要看条件。陆铭考察过湖南某市的石化企业，当地早有产业基础，选址又考虑了环境影响，这是他认可的例子。若缺少这些条件，只为增长引入项目，就可能付出环境和财政成本。他提到中国汽车年产量已超过
<strong>3000
万辆</strong>，在这样的规模下，继续靠补贴招来一家缺乏竞争力的车厂，投资可能落空，地方债务却留下来。</p>
<p>李翔进一步把“投资不过山海关”作为投资者用脚投票的例子。陆铭认可营商环境会影响企业选择，但反对用一句话污名化整个东北，也提到自己观察到辽宁的改善。对他而言，更有价值的竞争，是公平、法治、对民营企业友好的营商环境。发展条件好的地方企业多，可能不需要太多干预；条件较弱的地方若因缺钱、缺投资不断向少数企业提要求，又可能形成相反的循环。</p>
<p>只劝地方换观念还不够。税收与生产、注册和结算地点相关，GDP
和税收又影响考核，地方就有持续争项目的实际动力；人口流出的地区仍被要求不断扩大总量，尤其难以持续。他因此主张一起调整财政激励与评价标准。</p>
<p>汽车行业的价格压力，展示了这种竞争怎样传到人身上。地方扶持亏损企业，产能继续增加；下游大企业再把降价压力传给轮胎等供应商，上游逐层承压，还可能被拖欠账款。产量、出口和销售可以很好，产业链利润却很薄。这也是为什么陆铭在谈国际研究时强调，应从本土紧迫问题推进研究，同时承认相关成果仍在积累，不能把尚待回答的治理难题说成已有完整解法。</p>
<a id="人没时间消费有钱也未必发生010855011900"></a>
<a id="服务消费缺的不只有收入也可能是供给与时间"></a>
<h3 id="time-to-consume">人没时间，消费有钱也未必发生 <span class="picks-episode-time">（01:08:55–01:19:00）</span></h3>
<p>企业被压低价格后，可能减少员工、降低劳动成本，再让留下的人加班完成产量。陆铭引用“去年”的全国企业周平均劳动时间
<strong>48.6
小时</strong>，担心这种方式压缩了员工休息，也压缩了他们作为消费者的生活。他用一句尖锐的评价概括低价出口的这层代价：“牺牲了国内的消费者的福利，补贴了国外消费者。”这里的数字与判断均保留其访谈时的口径。</p>
<p>手机买下即可拥有，一顿聚餐、一场演出或一次运动，却必须拿出时间。随着服务业比重增加，工时过长就不只是劳工问题，也会阻碍服务消费和内需。他要求下游大企业承担产业链责任，关注供应商的利润、劳动标准与员工福利，而非只以更低采购价判断效率。</p>
<p><strong>但竞争这么激烈，一家公司敢先涨价吗？</strong>
李翔的追问使回答增加了条件。陆铭承认，在技术、质量较弱时，成本上升确实可能失去竞争力。他随后给出两组假设：如果国外卖
100，国内卖 99，涨到 101 可能就输了；但如果国外卖 100，中国企业已经卖到
50，只因国内同行又压到 49，那么价格回到 60 或
70，未必就失去国际竞争力。这些数字是用于区分两种竞争处境的例子，并非行业真实价差。</p>
<p>他主张的制度动作，是提高侵犯劳动权益、污染环境、侵犯知识产权的违规成本，避免大企业靠这些方式压低价格；亏损企业也应有正常退出机制，而非由地方不断补贴维持、继续扩产。大市场可以让产品快速卖向全国，恶性竞争却不是规模本身必然带来的结果，关键仍是规则和激励。</p>
<p>消费税改革是他给出的另一条思路。按访谈中的介绍，当时消费税覆盖面较窄，往往在生产环节征收，地方分享较少。他设想扩大覆盖面、把征收环节向消费端后移，并增加地方分享：地方若能从消费中受益，就更有动力改善公共服务和生活质量，吸引人留下消费。他同时强调，大的税制调整不能一蹴而就，短期仍需要考核、观念与行政协调的变化。</p>
<a id="第三部分--产业政策教育与研究"></a><h2 id="产业政策生活服务与教育">产业政策、生活服务与教育</h2>
<a id="产业政策可以协调什么谁来判断赢家011900013332"></a>
<a id="产业政策要解决协调问题也要承认自己不知道赢家是谁"></a>
<h3 id="industrial-policy">产业政策可以协调什么，谁来判断赢家 <span class="picks-episode-time">（01:19:00–01:33:32）</span></h3>
<p>新产业可能缺资金，也可能同时需要土地、税收安排、人才培养与跨地区配合。尤其在早期，市场前景尚不清楚，单个初创企业很难独自组织这些条件。因此，陆铭认为政府有协调的必要，真正要争论的是产业政策怎样实施。</p>
<p>他并不把借鉴国外经验简化为美国或日本二选一。美国私人企业参与重大科技项目、科研教育吸引全球人才，日本引进吸收技术、强调企业责任与海外合规，一些东南亚国家的社会组织关注弱势群体，都是他认为可学习的方面。但美国跨地区基础设施协调困难、日本长期补贴低效企业和过早押定狭窄技术路线，又是他提醒避免的另一面。李翔问这些长处是否与各自制度高度相连，他承认历史会塑造制度，随后强调，历史不能免除一个国家适应新阶段的任务。</p>
<p>阶段变化也会改变同一种投资的价值。基础设施不足时，地方负债修路可能有益；人口流出以后，八车道甚至十车道的道路，以及农村住房和建设用地出现闲置，再延续同样的扩张就需要重新计算需求。早期成功的做法不能因此获得永久有效的证明。</p>
<p>选择技术路线同样如此。陆铭提到，连大型企业内部，对 AI
应重点发展大模型还是具身智能，都可能存在分歧，甚至造成团队出走。政府若在此时认定自己知道赢家，先选定少数企业长期下注，就可能放大错误。政府与企业也可能相互强化同一种判断，使押注比单靠任何一方走得更远。他倾向于把支持范围放宽，让竞争和淘汰继续发生，并更多考虑在成功出现后奖励。</p>
<p>在中国，还须区分中央与地方产业政策。国家鼓励
AI、生物医药等方向，不等于每个地方都有同一产业的区位、人才、市场和配套。各地争着补贴同样的项目，可能把产业方向变成重复建设、地方债务和市场分割；法治、统一市场与税制改革，正是实施政策所需的环境。</p>
<p><strong>合肥的成功究竟证明了什么？</strong>
李翔提到地方投资的经验，陆铭要求把长三角区位、中科大等高校的人才、京东方当时的高成长阶段以及落地时机一起看。只看到政府出资，就容易忽略项目能长起来的条件。他还批评投资基金要求企业“返投本地”的做法：出资附带本地设厂、就业和税收要求，可能使选址偏离企业按成本收益作出的选择。基金的存在本身不证明效率，成功案例更不能直接成为各地复制的理由。</p>
<a id="演唱会散场以后消费为什么没有继续013332013808"></a>
<h3 id="service-and-education">演唱会散场以后，消费为什么没有继续 <span class="picks-episode-time">（01:33:32–01:38:08）</span></h3>
<p>观众散场后还能不能吃饭、活动，取决于周围有没有服务，也取决于时间安排。陆铭举到，一些演出要求半小时内疏散人群，地铁晚十点半就停运，原本可能发生的第二轮消费因此受到限制。这里说的是他举出的场景，不是所有城市和演出的统一安排。</p>
<p>同样的问题还出现在河道水上运动、年轻人的滑板空间、餐馆外摆：有需求，未必就能形成供给。陆铭以服务消费与部分服务价格上升为线索，认为供给和场景开放不足，是值得关注的潜力。他也反对把生活服务简单看成低端，医疗、教育、养老、卫生和幼托，正是居民生活质量的一部分。</p>
<p>需求还包括高收入人群的高尔夫、游艇等活动。他认为，国内缺乏相应供给，会把一部分消费推到国外，而适当发展这些服务也能创造就业。这个判断与前面的公共服务并列：不同人群需要不同供给，不能只看某一种消费。</p>
<p>人口和土地配置又会限制这些机会。按他的解释，人口流入可以增加较富裕、老龄化地区的劳动供给，但地方可能把外来人口视作额外支出，认为自己缺钱、缺地。以上海为例，他口述约
6000
平方公里的土地中仍有约三分之一用于种植，借此追问土地用途是否适合当地人口和住房需求。产业潜力存在，并不意味着既有制度会自动释放它。</p>
<a id="ai-对教育的挑战是教什么而不只是多读几年"></a>
<a id="ai-时代大学要改变的是教什么013808014332"></a>
<h3 id="ai-education">AI 时代，大学要改变的是教什么 <span class="picks-episode-time">（01:38:08–01:43:32）</span></h3>
<p>当记忆、背诵、演算、推导中的一些任务可以交给
AI，大学有限的时间应该重新分配。陆铭把这些容易由机器完成的能力称作“机能”，随后立即限定：他不是主张中小学不再记忆和背诵，因为在他看来，这些训练仍有促进大脑发育的意义。他追问的是，到了大学，还应把多少时间放在同类作业上。</p>
<p>他主张增加跨专业选修、通识教育和接触企业、社会的实践，培养审美、价值判断、对政策和人类发展趋势的理解，以及对人性和市场需求的理解。教师和课程也要调整，不能只换上新的课程名，却继续把学生留在教室里完成同样的训练。他将这些能力视作
AI 时代尤其值得培养的方向。</p>
<p>李翔听后追问：为什么最担心的不是内需和人口，而是这些问题？陆铭解释，他并不否认居民缺钱，也赞同恢复增长、修复资产市场，以收入和财富效应支持消费；他强调服务供给和闲暇，是因为这些条件容易被漏掉。没有可用的服务场景，是供给问题；加班过长、没有时间消费，是需求受到时间约束的问题。</p>
<p>人口问题也有类似的时间差。他赞同提高劳动者素质等讨论，但提醒，从今天生下一个孩子，到成为劳动力至少还有
<strong>16
年</strong>，短期内不能靠鼓励生育增加劳动人数。现有劳动者能够流动到机会更多、收入更高的地方，则可能立即改善资源配置。他用在家乡月入
2000 元、换一个地方可能挣 4000 或 5000
元作假设，说明同一个人的劳动可以有不同回报，并非承诺迁城必然使收入翻倍。</p>
<p>所以教育的紧要问题也不只是延长在校年份、提高大学毕业率。若教的内容仍停留在更容易被机器替代的任务上，多读几年未必就回应了就业变化。职业与教育怎样适应，仍然回到前面那个问题：人的能力在什么环境中更能发挥作用。</p>
<a id="ai-也在改变经济学的研究对象稀缺性决策者与保障关系"></a>
<a id="ai-改变的不只是研究工具还有谁在决策014332014807"></a>
<h3 id="ai-economic-questions">AI 改变的不只是研究工具，还有谁在决策 <span class="picks-episode-time">（01:43:32–01:48:07）</span></h3>
<p>AI
帮助建模和统计，已经改变经济学的工作方法；陆铭更关心的是，研究对象也在变化。某些领域供给大幅增加，会重新分配稀缺性：原来稀缺的资源可能不再稀缺，原来不紧缺的反而受到更多需求。供给增加不自动等于所有约束消失。</p>
<p>人的决策也未必因为 AI
更理性。信息可能放大情绪，错误语料和幻觉可能带来错误判断。到了 Agent
可以代人决定的阶段，组织中还多出了一层代理关系：不只是人命令工具做事，而是需要重新安排代理权限、责任和相互约束。</p>
<p>组织形式随后也可能变小、变平。一个人加上
AI，可以成立一人公司，也可能不再处于传统雇主与雇员的关系中。陆铭因此追问，围绕雇佣关系设计的社会保险和保障，要怎样覆盖这些劳动者。这些都是研究议题，访谈没有提供完成的制度方案。</p>
<p>对算力的获得方式，他提出两种可能的模式：企业出资、收费回收投资，可能扩大付得起与付不起的个人和企业之间的差距；更普惠、公共化的供给，则可能降低使用门槛。他把中美正在探索的道路作这样的比较，并把后一种方向称为“AI
时代的社会主义”，这是他当时的判断。普惠也有代价：补贴算力会不会导致低效使用，甚至让企业用补贴加速替代员工、扩大就业压力？让更多人用得起，和让资源得到有效使用，仍需同时研究。</p>
<h2 id="研究怎样回应变化">研究怎样回应变化</h2>
<a id="方法越成熟为什么仍可能看不见新问题014807015808"></a>
<h3 id="research-methods">方法越成熟，为什么仍可能看不见新问题 <span class="picks-episode-time">（01:48:07–01:58:08）</span></h3>
<p>新问题可能缺数据、缺文献，也不容易放进已有模型。陆铭认可数学建模、统计和因果分析让经济学更科学；他的担心是，如果先用现成方法决定什么值得研究，复杂而紧迫的现实问题就容易被排除。问题应当先被提出，再寻找适当的方法，而不能因为不容易发表就不研究。</p>
<p>李翔追问，AI
等前沿研究正在从大学实验室走向企业，经济学会不会也如此？陆铭先说自己不敢判断经济学是否会发生同样迁移，然后解释他观察到的理工研究变化。第一是资本：某些
AI
研究动辄需要上亿元融资；第二是快速验证：模型要在企业的算力和真实应用场景中检验能力。大学既受资金限制，也未必拥有那些场景，企业因此成为重要研究场所。</p>
<p>他还提到企业直接招高中生的现象，并以此提醒大学，课程的价值不能只由文凭证明。大学也在调整：有的把数据计算与
AI
加入人文课程；他在外滩大会听到一位大学副校长说，自己的团队一直重视企业委托的“横向课题”，所以对团队适应变化更有信心。基础研究与应用可以互相支持，不应把联系企业一概看成去赚钱。</p>
<p>为什么较早一代经济学家能同时活跃在学术、政策和媒体领域，后来反而更难？陆铭回顾，以
1994
年北大相关研究中心的发展、武汉大学引入现代经济学教育为标志，中国经济学加快了与国际接轨。国际化缩小了方法差距，期刊发表和高校晋升的评价，也逐渐更紧地捆绑在一起。</p>
<p>这套评价能够鼓励严谨研究，却也可能让国内重要、但缺文献数据或制度难以解释的问题处于劣势。公众讨论和政策回应若被视作不务正业，研究会与社会逐渐脱节。他担心的不是同行评议本身，而是同行评议变成只在圈内互相打分，最终让社会甚至学生觉得这个学科与自己无关。</p>
<a id="如果-ai-公司邀请陆铭会去吗015721020025"></a>
<h3 id="company-research">如果 AI 公司邀请，陆铭会去吗 <span class="picks-episode-time">（01:57:21–02:00:25）</span></h3>
<p>他的第一个回答是犹豫。李翔设想大型 AI
公司邀请他去内部研究经济学，陆铭说，自己已经年过半百，离开还关系到研究院、团队和大学学科，不能只看个人愿望。随后他换了一个条件：假如自己是刚毕业、没有这些责任的
30 岁经济学者，他会愿意去。</p>
<p>原因是许多前沿问题正在企业内部产生，包括 AI
的伦理与经济问题、平台消费和新的组织方式。他的团队已经与平台及 AI
企业合作，也支持学生进入企业。他举出的具体行动是，一位当年毕业的博士正在面试大型平台研究院，研究平台消费；企业关注的问题和学界现有研究的角度，并不总是相同。</p>
<p>这个回答既保留了对企业研究机会的兴趣，也保留了角色、年龄和团队责任带来的差异。它不是对整个经济学都会迁入企业的预测，也与前面“没有适合所有人的选城建议”形成呼应：同样的机会，放在不同人的生活里，价值不同。</p>
<a id="参与政策研究怎样保留独立判断020025020855"></a>
<a id="研究要参与现实独立性体现在怎样得出结论"></a>
<h3 id="research-independence">参与政策研究，怎样保留独立判断 <span class="picks-episode-time">（02:00:25–02:08:55）</span></h3>
<p>可以关注政策制定者的问题，同时不接受预先给定的答案。陆铭认为参与和独立并不冲突；真正需要保持距离的，是研究尚未开始就已决定结论、只用论证去迎合。他呼吁经济学界作为一个群体更多回应社会需要，但并不要求每个学者都研究政策：擅长数学、抽象原理的人，也可以有自己的分工。</p>
<p>他以货币传导为例：如果宽松政策没有像预期那样带动消费信贷和投资，为什么会这样，本来就是经济学应该回答的问题。若研究不足以支持这类讨论，不能仅以“保持距离”解释学科对现实的缺席。</p>
<p>陆铭讲到，自己十年前的一些建议与当时政策并不一致，后来部分进入改革。他当然感到高兴，但不认为任务因此结束。参与规划咨询、向政府提供意见，与继续提出和现行做法不同的研究判断，可以同时存在。</p>
<p>公租房选址就是他举出的新问题。需要公租房的服务人员，工作可能集中在中心城区；如果只考虑建设数量，把住房放在很远的郊区，就可能让有需求的人无法使用，房子甚至闲置。把就业区位与住房供应联系起来，才看得出“建了多少”以外的问题，也可能因此提出把公租房向中心区安排的建议。</p>
<p>这种参与还包括面向公众解释研究。他提到欣赏克鲁格曼和爱德华·格雷泽对现实问题的关注，认为以专业研究为基础写专栏、做科普，也是服务社会。仅凭学者经常出现在媒体上，就否定其严肃研究，在他看来并不公平。</p>
<a id="第四部分--养老算力与数据"></a><h2 id="养老基础设施与数据">养老、基础设施与数据</h2>
<a id="想回家养老先看身体变弱以后谁能帮忙020855021201"></a>
<h3 id="care-and-return">想回家养老，先看身体变弱以后谁能帮忙 <span class="picks-episode-time">（02:08:55–02:12:01）</span></h3>
<p>一位与陆铭年龄相近的女性，17
岁去广州，在那里生活了很多年。她说自己喜欢广州，也在农村老家买了房、建了房。陆铭问她准备什么时候回去，她的回答是，等哪一天动不了了再回去。</p>
<p>陆铭没有把这个个案宣布为错误。他先限定自己只能谈大概率，随后提出与直觉相反的担忧：<strong>越是行动能力下降，越可能需要留在有医院、护工和熟悉朋友的地方。</strong>
身体好时，远一点、服务少一点可能还能应付；需要持续照护以后，这些条件就会变得更重要。</p>
<p>他设想，若许多人都按“动不了再回乡”来安排生活，其中可能有相当一部分最终回不去。这是他的情景判断，不是调查统计。提前在老家投入大量资金建房、买房，房子可能空置，在人口流出的市场也可能面对贬值风险；他担心这种预期既影响家庭资源安排，也影响公共服务要为谁、在哪里准备。</p>
<p>“难道不应该爱家乡吗？”是他在公共讨论中常遇到的回应。陆铭把几件事拆开：对家乡有感情，经常探望亲友；是否买房、建房或投资；身体不好时在哪里得到照护。三者可以分别决定。年轻时选城看职业和交往，后来可能要重新看医院、护工和亲友，这也是人生阶段会改变城市价值的具体例子。</p>
<a id="回应现实会不会牺牲研究的长期价值021201021553"></a>
<h3 id="research-and-reality">回应现实，会不会牺牲研究的长期价值 <span class="picks-episode-time">（02:12:01–02:15:53）</span></h3>
<p>陆铭认为，一般原理与具体制度可以放在同一项研究里。制造业减少用工、收入增加后服务需求上升，是他所说的普遍机制；外来人口能否使用公共服务、土地配置受到哪些限制，则是中国的具体条件。把两者结合，才能提出公租房该在哪里建、容积率能否调整等实际建议。</p>
<p>面对不同听众，可以分别强调机制或操作，研究并不因此变成两套互相矛盾的东西。真正的困难之一来自发表：不熟悉中国背景的读者，可能嫌制度说明过细，但如果过度简化，又无法理解问题。这样的成本是研究者需要面对的选择，不能反过来证明现实议题缺乏理论价值。</p>
<p>对话随后把协调问题放到 AI
基础设施上。李翔转述有人希望美国借鉴中国组织能源和基建投资的观点，陆铭认为，私人企业确实有难以独自完成的事情；需要进一步解释的，是哪一种投资和哪一层协调超出了单个企业的能力。</p>
<a id="研发可以聚在中心区算力另有选址条件021553021726"></a>
<h3 id="ai-infrastructure">研发可以聚在中心区，算力另有选址条件 <span class="picks-episode-time">（02:15:53–02:17:26）</span></h3>
<p>大型基础设施的收益，未必能由投资者通过市场收费全部收回来。有些缺少合适的定价，有些回收期可能是
<strong>10 年、20
年</strong>；跨行业、跨地区的配合，也不是单个企业有能力组织的。陆铭用这些条件说明政府协调的空间，而非仅因项目规模大就认定应由政府包办。</p>
<p>他举到中国中西部的算力和存储中心，以及戈壁、沙漠地区的光伏布局。AI
相关产业耗能高，基础设施要考虑能源条件、地理稳定性等因素，跨地区协调因此很重要。他认为中国已有的协调能力仍可进一步发挥。</p>
<p>把这一段与前面的旧金山例子合看，同一个产业里，不同活动需要不同地点：创新团队可能追求中心区的人才与交流，算力、存储及能源设施则有自己的条件。AI
加强某些城市的集聚，并不意味着所有相关投资都要挤到同一块地方。</p>
<a id="数据打通为什么不只是技术问题021726022050"></a>
<h3 id="data-coordination">数据打通，为什么不只是技术问题 <span class="picks-episode-time">（02:17:26–02:20:50）</span></h3>
<p>平台数据有企业和行业边界，政务数据也分散在部门与地区。陆铭强调，要统一利用数据，还要考虑生成这些数据的公司和个人如何得到补偿，不能只谈“拿出来”而忽略贡献者的利益。</p>
<p>李翔追问，部门之间打不通，究竟是技术还是制度摩擦？陆铭回答两者都有。技术上，存储格式、时间变量不一致，同一个人或企业未必能在不同数据里被准确对应。制度上，负责人未必愿意分享，数据统筹部门与其他部门平级，也不容易组织跨部门、跨地区协调。</p>
<p>因此，政府具有较强组织力量，并不等于一切想做的事都能立即完成。陆铭最后把障碍落到权力如何配置：权力按部门和地区划分，处理辖内事务可能很有效；一旦需要跨越边界，同样的划分又可能成为阻力，需要更高层次的协调。</p>
